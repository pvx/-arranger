# Aranger

Одностраничная проверка раскроя: отрезки укладываются в заготовки длины R. Правила размещения живут в `src/packing.ts` (чистые функции, без React). Эксперимент — ввод, история, localStorage — в `src/App.tsx`. Текст для пользователя на английском.

## milli

Длины внутри алгоритма — целые тысячные доли (`1200` = 1.2). Сложение и сравнение идут в этих целых, поэтому `0.1 + 0.2` сходится в `0.3`. Через границу длина проходит только через `parseLength` (внутрь) и `fmt` (наружу). Новая арифметика длин остаётся в milli.

## Размещение

`pack` перемешивает экземпляры (Fisher–Yates) и кладёт их First Fit: первая по порядку создания заготовка, куда длина ещё входит, иначе новая.

Любая укладка кодируется порядком «заготовка за заготовкой». First Fit по такому порядку берёт не больше заготовок, чем исходная укладка, и может разложить отрезки иначе. `exactPack` возвращает найденное именно так — `packOrder` от `best.flat()`, — чтобы экран и история показывали результат First Fit. Число заготовок при этом сохраняется.

`lowerBound` — оценка Martello–Toth L2: меньше заготовок не бывает. Оценка бывает недостижимой; тогда оптимум выше неё.

`proven` значит, что перебор дошёл до конца. Упор в `EXACT_LIMIT` отдаёт лучшее найденное с `proven: false`. Поиск синхронный, в UI-потоке; лимит держит паузу около секунды. Строка `ponytail:` у лимита — принятый долг: вынос в worker делается отдельной задачей.

В переборе заготовки с одинаковым `used` равнозначны, вторая не исследуется.

`validate` собирает все ошибки и возвращает разобранные позиции. Запуск из UI идёт при пустом списке ошибок. Длина больше R — ошибка валидации, а `firstFit` на таком отрезке бросает.

Тест, которому важен порядок, передаёт свой `rand` в `pack` / `shuffle`.

## Эксперимент

Правка R, строки или количества — новый эксперимент: результат, история, счётчик прогонов и точный перебор сбрасываются.

Серия показывает укладку с минимумом заготовок; при равенстве остаётся более ранняя. В историю строка попадает на первом новом суммарном остатке (остаток однозначно задаётся числом заготовок). Подсветка выбранной строки держится на той же ссылке результата, что лежит в истории.

Оптимум доказан, когда `exact.proven`, либо когда лучшее число заготовок в истории равно `lowerBound`. Текст различает два случая: оптимум совпал с оценкой, и оценка недостижима, но перебор доказал большее число.

Первый прогон при открытии один: ref `started` гасит повторный эффект StrictMode.

Ключи localStorage — `aranger-input-v1` и `aranger-runs-v1`. Загрузка доверяет объекту с полем `r` и массивом `rows`. Новая форма записи — новый суффикс ключа.

`MAX_QTY` и `MAX_RUNS` держат синхронную работу в UI-потоке короткой. Больший предел поднимается вместе с выносом работы из потока.

## Проверка

Правка `packing.ts` закончена, когда `npm test` зелёный и новое правило покрыто случаем рядом с тем, которое оно меняет. `packing.test.ts` входит в `tsc`: ошибка типов в тесте роняет и `npm run build`.

Правка интерфейса закончена, когда сборка проходит и в браузере пройден затронутый сценарий: ввод, прогон, история, сброс при правке, точный перебор.
